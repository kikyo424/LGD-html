# 여백 YEOBACK

일상에 잠깐의 쉼을 제안하는 가상의 카페 랜딩페이지입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치나 빌드 과정이 없으며 외부 이미지·폰트·스크립트 요청 없이 동작합니다.

## 파일

- `index.html`: 한국어 콘텐츠와 페이지 구조
- `styles.css`: 데스크톱·태블릿·모바일 반응형 스타일, CSS 메뉴 일러스트
- `assets/cafe.png`: AI로 생성한 카페 이미지

메뉴와 방문 안내는 가상 브랜드 설정이며 실제 매장·주문 서비스를 제공하지 않습니다. 내비게이션과 버튼은 페이지 안의 해당 섹션으로 이동합니다.
